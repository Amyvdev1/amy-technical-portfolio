# Amy Villa — Technical Portfolio

A recruiter-ready personal portfolio for **Amy Villa**, an early-career software developer and systems builder. The site presents three clearly labeled self-directed demonstrations in workflow operations, backend/API design, and customer operations.

## Selected demos

- **RelayOps** — a workflow dashboard that makes task ownership, approval, state, and handoff visible.
- **ClearRoute API** — a FastAPI workflow API sample with validation, role-aware demo access, audit events, and automated tests.
- **ClientFlow Studio** — a customer-operations interface for lead context, follow-up stages, notes, and next actions.

## Evidence boundary

All examples are personal portfolio demonstrations. They use sample data only and do not represent client work, user data, production deployments, or commercial outcomes.

```bash
pnpm install

```
