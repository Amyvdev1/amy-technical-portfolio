# Signal Engine — Visual Validation

## Desktop

The rebuilt first scene is a true full-screen visual environment rather than a portfolio header. It combines an original cobalt signal-core environment with layered native HUD telemetry, scene navigation, a cursor-responsive optical lens, animated scanline, orbiting core geometry, and copy that changes by scroll chapter. The visual hierarchy keeps the message legible while the signal core functions as the main cinematic object.

## Mobile

At 390 × 844, the visual core remains the dominant element without obscuring the message. The navigation is condensed, telemetry is reduced, typography remains readable, and chapter information stays present as an overlaid HUD. The experience uses no video and keeps a reduced-motion fallback.

## Reference translation

The result uses the benchmark’s interaction category—scroll-driven scene progression, HUD information density, a central cinematic object, and a product-world framing—without reproducing the Iron Man fan-site concept, imagery, language, colors, or layout. Amy’s palette, systems narrative, blue signal core, and Nocturne/Panther world remain distinct.

## Live scroll check

In the interactive browser preview, the Signal Engine opened after its loader and retained the fixed cinematic stage while the page scrolled. At 22% scroll, the HUD’s live scroll data updated to `022%`, while the grid, scan layer, cursor-responsive lens, core object, chapter navigation, and content remained anchored as designed. The second scene begins just after 25% of the pinned chapter range; this confirms the scroll-dependent stage is using its full intended progression rather than behaving as a conventional scrolling hero.
